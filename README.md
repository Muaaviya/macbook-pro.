# 💻 MacBook Pro - 3D Landing Page

A sleek **3D interactive landing page** featuring a **MacBook Pro** model that opens and closes smoothly as you scroll.  
Built using **React**, **Three.js**, and **TailwindCSS**, this project demonstrates the fusion of modern frontend development with immersive 3D experiences.

---

### 🚀 Features

- ✨ Realistic 3D MacBook Pro model
- 🎞️ Scroll-based animation (opens and closes with user scroll)
- ⚡ Built with high-performance 3D rendering using `react-three/fiber`
- 🧩 Smooth user experience powered by `@react-three/drei` and `TailwindCSS`
- ⚙️ Fast development setup with `Vite`

---

### 🛠️ Tech Stack

- **React** – Frontend library
- **Three.js** – 3D graphics engine
- **@react-three/fiber** – React renderer for Three.js
- **@react-three/drei** – Helpers and abstractions for easier 3D work
- **TailwindCSS** – Utility-first CSS framework
- **Vite** – Next-gen frontend build tool

---

### 📦 Installation & Setup

1. Clone the repository

```bash
git clone https://github.com/Muaaviya/macbook-pro..git
```

2. Navigate into the project folder

```bash
cd macbook-pro
```

3. Install dependencies

```bash
npm install
```

4. Start the development server

```bash
npm run dev
```

### 🧠 How It Works

The project uses scroll-based animation logic to control the MacBook 3D model’s rotation and lid opening.
By syncing the scroll position with useFrame and useScroll from @react-three/drei, the model animates naturally as you move through the page.
